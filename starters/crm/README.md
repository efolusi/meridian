# CRM — starter journey

Copyable revenue-team journey: pipeline → accounts → account detail. All records are labelled sample data; replace them with connected customer data before production use.

- `Pipeline.dc.html` — stage-based opportunity board with owner and next action
- `Accounts.dc.html` — searchable account index
- `AccountDetail.dc.html` — relationship timeline, contacts, and open work

Copy this whole folder, then change the single `base` line in `ds-base.js` to point at your Meridian root.
