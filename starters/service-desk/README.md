# Service desk — starter journey

Copyable support-operations journey: triage queue → ticket catalogue → incident record. Sample tickets avoid fictional performance claims and keep ownership, urgency, and audit context visible.

- `Queue.dc.html` — live triage workspace with next-action context
- `Tickets.dc.html` — filterable ticket catalogue
- `TicketDetail.dc.html` — complete incident record and response timeline

Copy this whole folder, then change the single `base` line in `ds-base.js` to point at your Meridian root.
