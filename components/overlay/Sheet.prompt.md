# Sheet

Slide-in dialog for supplementary workflows that should preserve page context. Compose `Sheet`, `SheetTrigger`, `SheetContent`, `SheetHeader`, `SheetTitle`, `SheetDescription`, `SheetFooter`, and `SheetClose`. Content supports `top`, `right`, `bottom`, and `left` sides.

Use a regular Dialog when the task deserves centered attention; use Drawer for gesture-driven mobile surfaces.
