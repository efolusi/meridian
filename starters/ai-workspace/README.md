# AI workspace — starter journey

Copyable AI operations journey: workspace → knowledge → evaluations. The records are explicitly sample data so teams can replace them without inheriting fictional performance claims.

- `Workspace.dc.html` — review queue, active run, sources, and approval action
- `Knowledge.dc.html` — source library and ingestion status
- `Evaluations.dc.html` — evaluation suites and recent results

Copy this whole folder, then change the single `base` line in `ds-base.js` to point at your Meridian root.
