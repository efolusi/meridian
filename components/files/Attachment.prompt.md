# Attachment

Compose a file attachment from `Attachment`, `AttachmentMedia`, `AttachmentContent`, `AttachmentTitle`, `AttachmentDescription`, and optional `AttachmentActions`. Use `AttachmentTrigger` for a full-card action and `AttachmentGroup` for a horizontally scrollable collection. Label icon-only actions and triggers with `aria-label`; include a written failure reason when `state="error"`.
