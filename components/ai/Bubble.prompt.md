# Bubble

Use Bubble for compact conversational content. Group related bubbles, choose a semantic visual variant, align a sender's content to the end, and add reactions only when they remain useful after the message is read.

```jsx
<BubbleGroup>
  <Bubble variant="secondary"><BubbleContent>Can you review the release?</BubbleContent></Bubble>
  <Bubble align="end"><BubbleContent>Yes, all checks passed.</BubbleContent></Bubble>
</BubbleGroup>
```
