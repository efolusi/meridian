# Finance operations — starter journey

Copyable finance-team journey: cash-flow map → transactions → reconciliation. It presents operational sample records without asserting fictional company metrics.

- `Cashflow.dc.html` — spatial map from collection accounts through controls to destinations
- `Transactions.dc.html` — reviewable transaction index
- `Reconciliation.dc.html` — staged close workflow with ownership and evidence

Copy this whole folder, then change the single `base` line in `ds-base.js` to point at your Meridian root.
